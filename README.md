# QA Portfolio 

**QA | Test Automation | API Testing | AI-Assisted QA**

This repository is a collection of my practical QA and test automation projects, covering **manual testing concepts, API testing, UI automation, risk-based test design, CI/CD, and AI/LLM testing**.

My focus is on building tests that provide meaningful coverage rather than simply increasing test count.

I am an aspiring **QA / QA Automation Engineer** developing practical experience through hands-on testing and automation projects.

## 🥈 Gemini LLM Testing

**JavaScript · Node.js · Gemini API · LLM Testing · Automated Evaluation**

[View Repository](https://github.com/nadjacelsalc/gemini-llm-testing)

A QA automation project focused specifically on testing **Large Language Model behavior**.

Unlike traditional API or UI testing, LLM testing often requires evaluating whether a response satisfies a semantic expectation rather than matching an exact value.

The project explores:

* LLM test case design
* Structured test data
* Expected behavior
* Positive and negative scenarios
* Automated response evaluation
* Semantic evaluation
* Evaluator design
* AI output validation

The project is being developed incrementally, starting with simple deterministic assertions and progressing toward semantic evaluation where traditional assertions are insufficient.

# 🤖 AI-Assisted QA

AI is an area I am actively exploring as part of modern software testing.

My interest goes beyond using AI to generate test code. I am investigating how AI can support the **QA process itself**, including:

* identifying missing test scenarios;
* analyzing test coverage;
* identifying redundant tests;
* generating candidate test cases;
* evaluating AI-generated outputs;
* defining expected LLM behavior;
* and automatically evaluating LLM responses.

The Playwright project explores **AI-assisted test analysis and risk-based testing**, while the Gemini project focuses specifically on **testing LLM behavior and evaluating generated responses**.
